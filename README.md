# Arduino-Function-Generator-v1.0
8 bit DAC that simulate 6 types of signals

# Components and schematic
- 2x TL082
- 3x 1kΩ resistors
- 1x 16kΩ resistor
- 2x 4x resistors from 2^1kΩ to 2^4kΩ

- VCC for the OpAmps is ± 10V

# Use
- download the `.ino` file and load it in the Arduino board
